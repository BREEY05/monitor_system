改进的多 Agent Workflow 架构

工业环境智能监控系统 — 从线性 Pipeline 到 DAG 工作流引擎的演进

v1 原架构局限

  • 线性流水线：单次执行无条件分支
  • 无状态通信：每轮对话独立无记忆
  • 无质量保障：Agent输出直接返回
  • 纯被动响应：只能响应用户查询
  • 无Agent间通信：结果只在末尾合并
  • 刚性调度：计划生成后不可变更

v2 增强架构改进

  • DAG 工作流：条件分支 + 并行 + 动态重试
  • 对话记忆：短期滑动窗口 + 长期用户画像
  • 自评估循环：质量门控 + 自动重试 + 降级
  • 主动监控：统计异常检测 + 巡检报告
  • 黑板通信：Agent间共享中间结果
  • 动态重规划：根据中间结果调整执行计划

基础使用

主动监控
# 创建增强编排器（一行代码启用所有新特性） from agents import create_enhanced_orchestrator orch = create_enhanced_orchestrator( backend="ollama", model="qwen3.5:0.8b", enable_memory=True, # 对话记忆 enable_evaluator=True, # 自评估循环 enable_monitor=True, # 主动监控 quality_threshold=0.5, # 质量阈值 ) # 处理消息（自动记忆、评估、监控） result = await orch.handle_message("当前温度多少？") print(result["reply"]) # AI 回复 print(result["quality"]) # 质量评估分数 print(result["monitor_status"]) # 监控状态
# 对话记忆 — 支持多轮上下文感知 await orch.handle_message("温度多少？") await orch.handle_message("刚才那个数据正常吗？") # 自动解析"刚才"引用 await orch.handle_message("帮我查一下相关的知识库文档") # 知道"相关"指温度 # 查看用户画像 profile = orch.get_memory_profile() # {"query_count": 3, "top_intents": {"sensor_query": 2, "knowledge": 1}, ...} # 查看评估统计 stats = orch.get_eval_stats() # {"total": 3, "avg_score": 0.78, "pass_rate": 1.0, ...}
# DAG 工作流 — 自定义复杂任务编排 from agents.workflow_engine import WorkflowDefinition, ConditionRule wf = WorkflowDefinition(name="deep_alarm_analysis") # 定义节点 wf.add_node("alarm", "task", agent_name="alarm") wf.add_node("sensor", "task", agent_name="sensor") wf.add_node("quality_gate", "gate", dependencies=["alarm", "sensor"]) wf.add_node("knowledge", "task", agent_name="knowledge", dependencies=["quality_gate"]) wf.add_node("fuse", "merge", dependencies=["quality_gate", "knowledge"]) # 条件分支：质量低时走重试路径 wf.add_condition("quality_gate", ConditionRule( field_path="gate.quality_gate.quality_score", operator="lt", value=0.5, target_node="alarm" # 质量低时重新查询报警 )) # 执行工作流 result = await orch.workflow_engine.execute(wf, message="分析报警原因并给出建议")
# 主动监控 — 周期性异常检测 # 手动触发健康检查 alerts = await orch.run_proactive_check() for alert in alerts["alerts"]: print(f"[{alert['severity']}] {alert['description']}") # 生成巡检报告 report = await orch.generate_report(period="day") print(report["summary"]) # LLM生成的自然语言巡检摘要 # 查看监控统计 stats = orch.get_monitor_stats() # {"check_count": 42, "total_anomalies": 3, "recent_anomaly_types": {...}} # StatisticalDetector 检测类型： # - Z-Score异常（偏离均值>2.5σ） # - 变化率异常（骤升骤降） # - 阈值接近度（即将触发报警） # - 数据停滞（传感器可能掉线）
